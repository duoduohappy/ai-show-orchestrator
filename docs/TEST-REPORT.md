# 演出项目测试报告

测试环境：Windows、OBS 33.0.1、obs-websocket-js、本机 Node.js 24.21.0。

- 控制器测试 9 个场景：身份、发布前置、版本失效、重复请求、发送前失败、回执丢失后恢复、人工接管、服务重启和网关租约通过。这里的 OBS 响应为测试夹具，不能计作真实设备测试。
- 真实 OBS 三段自动播放完成，场次耗时 15148 ms。三次软件 API 回读耗时为 [75, 75, 77] ms。这包含连接和请求往返，不是音视频端到端延迟。
- 真实 OBS 故障演练：发送前注入一次失败，暂停且不跳过未执行 cue；恢复和重复请求校验通过。
- 网关拓扑：本机独立 HTTP 服务、持久化队列、鉴权出站网关、素材校验与真实 OBS 联调通过。单次 cue 回读耗时 411 ms，包含轮询等待。
- DOM 集成测试：操作员登录、持久化控制入口与可播放素材通过。

证据：real-show-e2e.json、fault-recovery.json、gateway-e2e.json、obs-actual-output.png。real-obs-demo.mp4 为真实 OBS 输出的 55 张截图按采样时间合成的无音频样片；不是 OBS 原生全帧录制。

网关测试运行在本机模拟云端拓扑，尚未真实部署 Render。未验证实体灯光、调音台、实际摄像机、跨公网时延或生产不停演能力。未完成完整浏览器视觉验收。

Render 配置已通过官方 JSON Schema 结构校验，两个项目各自独立服务；默认免费配置不挂载磁盘，重启后的数据保留不属于云端验收项。SQLite 在线备份已生成并通过 PRAGMA integrity_check；该结果不代替真实 Render 部署和重启验收。
