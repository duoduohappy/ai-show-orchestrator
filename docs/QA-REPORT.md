# 本轮回归测试报告

测试日期：2026-11-20。环境：本机 Windows、Node.js 24.21.0、OBS 33.0.1。

## 已验证

- 原有模拟引擎和 9 组控制器测试通过。
- 新增 9 组回归：错误操作不打断演出、编排原子校验、自动时间线、延迟回执恢复、尾段异常与超时、重启废弃旧指令、异常网关回执。控制器回归使用夹具响应。
- 新增 16 项 HTTP 检查通过，包括视频分段读取。
- 免费 Render 环境本机模拟 9 次 HTTP 检查通过：安全登录、未配置模型、离线网关失败后解除忙碌状态、新实例还原。
- DOM 检查通过：加载失败可重试、恢复清理错误、服务端操作入口及媒体访问正常。
- 真实 OBS 三段演出完成：15,154 ms，三次 API 回读 122/62/61 ms；故障暂停、恢复与重复请求检查通过。样片来自 55 张真实 OBS 输出截图合成，无音频。

## 已修复

请求体异常、视频 Range 支持、未知接口状态码、非法操作产生虚假故障、自动 cue 被提前推进、延迟回执误判、尾段媒体异常与超时、旧网关指令重放、异常回执，以及页面加载恢复。

## 如何复现与边界

安装 Node.js 24 后执行 `npm ci`、`npm run test:all`。该命令无需模型或 OBS，使用隔离临时数据库。真实依赖验证另执行 `npm run test:e2e`。

未在真实 Render 实例验收；DOM 检查不代替完整浏览器视觉验收。未验证实体舞台设备、银行接口或生产负载。模型来源标签通过不等于每句话语义正确。免费实例冷启动恢复测试数据属于约定行为。
